# Restored and custom Domains

The prior nine-Domain reduction is reversed. The established catalog again contains 36 Domains:

Air, Earth, Fire, Water, Light, Dark, Sun, Moon, Lightning, Ice, Metal, Chaos, Law, Good, Evil, Creation, Destruction, War, Peace, Fear, Wrath, Love, Hope, Despair, Sorrow, Fate, Dreams, Nightmares, Life, Death, Spirit, Psionic, Nature, Void, Storm and Magic.

Time → Fate, Space → Void, Mind → Psionic and Plant → Nature remain spelling aliases; Plant is still a separate creature Type. Other established Domains remain distinct. Retained `domainThemes` from the earlier migration recover the original affinities, removing their inferred merged replacement. Elemental Techniques recover their original Domain from the saved theme without changing IDs, names, learned progress, equipped slots or running timers. If a historical theme was not retained in a third-party save, its erased identity cannot be reconstructed reliably.

## Discovery and persistence

A lineage's first actual encounter rolls a 2% chance to document a custom Domain. Failed rolls are remembered, preventing rerolls by revisiting. Discoveries use named spiritual motifs and bounded affinity-based passive variations; they are not arbitrary stat bonuses. Registration also supports valid custom names in generated/imported lineages, with a persisted affinity and description. Unsafe/invalid names are rejected. Custom definitions travel in the journey and species metadata so backups and the shared species library can restore them.

All Domains participate in innate/equipped/temporary classification sources, matching-Technique bonuses, generated learned Domain Techniques, compatibility restrictions, suppression and passive training. Temporary/equipped grants do not add passive slots. The original 36-Domain effectiveness chart is restored. Custom Domains start neutral against unrelated Domains rather than silently borrowing a whole resistance chart. A matching Type now grants 1.5× damage. A second distinct matching Type adds 5%; matching Domains add 10%, 5%, 2.5%, and so on. Supplemental matches share a 25% cap above the usual same-Type bonus (maximum 1.75×). Each Type or Domain advantage adds 100% and each resistance subtracts 25%; total effectiveness remains 0.5×–2× with no immunities. The Fire-versus-Plant advantage follows the same rule.

## Passive identity

The 21 core pools (twelve Types and nine broad affinities) retain 336 individually curated choices. Each restored or custom Domain receives sixteen named variations derived from an appropriate core family, with small bounded value differences. These additional pools are thematic variations, not a claim that hundreds of new bespoke mechanics were authored. Selection, unlocks and training are separate for every innate classification and individual.

All effect kinds retain the 25% sum cap. Reactive drain/thorns still resolve once per chain without recursion. Conditional effects use the actual target, Health ratio, previous Technique, weather and terrain. Existing valid trained selections are retained; legacy IDs migrate deterministically when a restored classification needs a new pool entry. The core values remain in `curated-passives.csv`; runtime variations are generated by `classification-passives.mjs`.
