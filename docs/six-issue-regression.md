| Reported issue | Current behavior | Regression evidence |
|---|---|---|

| Linked file loses to browser startup data | Read the linked file before the browser journey or library. Reading requires read permission only. If writing is unavailable, load the primary file and pause writes. Existing physical-site, stage persistence and artwork checks remain covered. |

Empty/unconscious-party guards, rank locks, maximum-active wording and early championship requirements are tested. |

| Practice shows “Speed undefined” | Display the Technique's real GCD/LCD, with a separate Technique recast where applicable, instead of the removed Speed property. | The actual practice dialog contains cooldown timing and no undefined/Speed text. |
