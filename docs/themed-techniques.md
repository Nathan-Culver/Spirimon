# Lineage, Type, and Domain techniques

The catalog adds 594 techniques: three for each of 150 roster lineages (450), each of twelve Types (36), and each of 36 established Domains (108). These are additions to existing techniques, not replacements. Their names, combat roles, visual motifs and effects follow each creature or classification. For example, Kilnscale learns Porcelain Rattle, Hinged Curl and Temple Bell Roll; Dewveil learns Amber Dewshot, Nectar Poultice and Sundew Entanglement.

| Source | Learning levels | Form requirement |
| --- | --- | --- |
| Lineage | 6, 18, 36 | First, second, third form respectively |
| Type | 5, 13, 25 | Any form |
| Innate Domain | 8, 20, 32 | Any form |

Each set includes an opening attack, a preparation or disruption action, and a stronger or conditional culmination. Resource costs use the existing Stamina/Willpower rules. Preparations have a 22-second independent recast; opening attacks have a six-second recast, and culminations fourteen seconds, in addition to the normal GCD where applicable. Existing Speed and style modifiers apply. Multi-hit and draining moves have lower per-hit power. These are tactical alternatives rather than replacements for every existing move.

Lineage signatures belong only to their lineage. Type techniques follow the species' two Types, and Domain techniques follow innate Domains. Equipping a Domain-granting move does not permanently unlock that Domain's whole learnset. Procedural lineages receive their own stable three-technique set. Newly discovered custom Domains receive three distinct named techniques with mechanics and imagery inherited from the Domain's registered affinity.

Practice at a safe place equips eligible learned techniques. The technique information panel identifies the lineage, Type or Domain tradition. The Menu handbook explains the learning milestones.

Migration appends eligible techniques without replacing equipped moves, learned IDs, timers, or current resources. Refreshing a species after custom-Domain discovery adds that Domain's techniques. Existing ordinary techniques retain their progression order. Each new technique uses the technique-specific animation system, including its effect family, visual motif, palette and deterministic choreography.

Validation: 700 regression tests pass. Dedicated checks cover exact coverage and unique names/IDs, actual roster-prefixed identities, level/form eligibility, classification exclusivity, custom-Domain updates, idempotent migration and combat resolution/animation for all 594 additions. The generated move-balance audit includes these additions.
